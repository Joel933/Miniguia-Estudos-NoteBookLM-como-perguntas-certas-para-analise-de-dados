# Miniguia-Estudos-NoteBookLM-como-perguntas-certas-para-analise-de-dados
**##Contexto e Objectivos**

**#Contexto##**
A Análise de Dados não depende apenas do domínio de ferramentas como Excel, SQL, Power BI ou Python. Um dos fatores mais importantes para obter bons resultados é saber formular as perguntas certas. Perguntas bem elaboradas orientam a exploração dos dados, facilitam a identificação de padrões e ajudam a gerar insights que apoiam a tomada de decisões.

Este projeto tem como objetivo demonstrar como o NotebookLM pode ser utilizado como uma ferramenta de aprendizagem ativa, auxiliando estudantes e iniciantes a desenvolverem a habilidade de criar perguntas estratégicas para projetos de Análise de Dados.

**#Objectivos#**
  	-Explicar por que fazer as perguntas certas é importante na análise de dados.
	-Apresentar diferentes tipos de perguntas utilizadas em projetos de análise de dados.
	-Demonstrar como melhorar prompts para obter respostas mais úteis da IA.
	-Criar um conjunto de perguntas reutilizáveis para diferentes cenários de análise.
	-Desenvolver um guia prático que possa ser utilizado em futuros projetos.

**#Dificuldades Encontradas (Cicatrizes)#**

Durante o desenvolvimento do projeto foram observadas algumas dificuldades.

Perguntas muito abertas produziam respostas superficiais.
Alguns prompts geravam respostas longas e pouco objetivas.
Em alguns casos foi necessário pedir exemplos para compreender melhor os conceitos.
A qualidade das respostas aumentou quando os prompts passaram a incluir contexto e objetivo.

**#Glossario#**
Análise de Dados: Processo de coletar, organizar, explorar e interpretar dados para apoiar decisões.
Dataset: Conjunto organizado de dados.
Insight: Descoberta relevante obtida após a análise dos dados.
KPI: Indicador utilizado para medir desempenho.
Métrica: Medida utilizada para avaliar resultados.
Dashboard: Painel visual que apresenta indicadores importantes.
Prompt: Instrução enviada para uma Inteligência Artificial.
Engenharia de Prompts: Técnica de criar e aperfeiçoar prompts para obter respostas mais úteis.
